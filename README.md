# 体测成绩计算器 · 国家标准 / 北京市九年级现场考试

单页、零依赖的体测成绩计算器，内置两套官方评分标准，可在页面顶部一键切换：

- **北京市义务教育体育与健康考核评价现场考试（2023 年试行评分标准）**：九年级，满分 30 分

## 功能

### 国家标准（100 分制）

- 覆盖小学一年级至大学四年级共 16 个组别，男女分开，指标与权重随组别自动切换
- 小学含 1 分钟跳绳（五、六年级另加 50 米 × 8 往返跑）；初中以上换成引体向上（男）/ 1 分钟仰卧起坐（女）与 1000 / 800 米跑
- 参考档位 100 / 90 / 80 / 60：切换档位时各输入框的灰色默认值同步变化，也可一键填入整档成绩
- 附加分按学段实现：小学 1 分钟跳绳最多 +20；初中以上引体向上 / 仰卧起坐、耐力跑各最多 +10
- 学年总分以 100 分为满分线，附加分可使总分超过 100（最高 120）

### 北京市现场考试（30 分制）

- 四类项目：素质项目Ⅰ（必考 8 分）、素质项目Ⅱ（六选一 8 分）、运动能力Ⅰ（六选一 8 分）、运动能力Ⅱ（四选一 6 分）
- 素质项目Ⅱ按性别给出不同选项：男为引体向上 / 双杠臂屈伸 / 实心球 / 跳绳 / 纵跳摸高 / 立定跳远，女为斜身引体 / 仰卧起坐 / 实心球 / 跳绳 / 纵跳摸高 / 立定跳远
- 运动能力Ⅰ含足球、篮球、排球、乒乓球、羽毛球、100 米游泳；其中游泳在原表中最高只列到 6 分，页面会提示这一差异
- 运动能力Ⅱ采用逐动作勾选：动作质量 5 分按漏做 / 做错的动作扣分，动作表现一档 1 分，界面实时合成 6 分制得分
- 记忆每个选项各自已填的成绩，来回切换选考项目不丢数据

### 通用

- 右侧常驻结果面板：总分、各项得分、已填项、单项明细
- 页尾折叠展示全部评分表，当前适用列（性别 / 所选项）高亮

## 规则说明

### 国家标准

- 学年总分 = 标准分（各单项得分 × 权重求和，满分 100）+ 附加分（最多 20）
- 等级：≥ 90 优秀、80—89.9 良好、60—79.9 及格、59.9 及以下不及格
- BMI 只有 100 / 80 / 60 三档，故选择 90 分档时按“正常”区间代入，总分为 91.5（页面内已注明）

### 北京市现场考试

- 现场考试满分 30 分 = 素质项目Ⅰ（8）+ 素质项目Ⅱ（8）+ 运动能力Ⅰ（8）+ 运动能力Ⅱ（6）
- 成绩达到表中某一档标准即得该档分值，未达最低一档计 0 分
- 页面不设等级（官方按 30 分制计分），只给出得分率作横向参照
- 体育与健康考试总分 70 分 = 过程性考核 40 分 + 现场考试 30 分，本页只估算现场考试这 30 分

结果仅用于自测估算，最终成绩以学校或考试机构核定为准。
