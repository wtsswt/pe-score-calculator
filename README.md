# 体测成绩计算器

面向学生自测的体质健康成绩计算工具。单文件纯静态网页，内置两套现行官方评分标准，可在页面顶部切换：

| 标准                               | 适用对象                 | 分制           |
| -------------------------------- | -------------------- | ------------ |
| 《国家学生体质健康标准（2014 年修订）》           | 小学一年级至大学四年级，共 16 个年级 | 100 分制，另设附加分 |
| 《北京市义务教育体育与健康考核评价现场考试项目评分标准（试行）》 | 九年级                  | 30 分制        |

在线使用：<https://wtsswt.github.io/pe-score-calculator/>

---

## 一、项目概述

本项目将上述两套标准中的评分表完整录入为结构化数据，依据录入成绩实时换算单项得分与总分，并给出等级或得分率。工具不连接任何服务器，全部运算在浏览器本地完成。

**设计目标**

1. 结果可追溯：每一项得分均可回溯至评分表中的具体档位。
2. 使用零门槛：无需安装、无需注册，下载单个 HTML 文件即可运行。
3. 数据不出本机：不采集、不上传任何输入内容。

---

## 二、适用范围与边界

**适用于**

- 学生个人测算《国家学生体质健康标准》学年总分与等级，评估各项短板。
- 九年级学生测算北京市现场考试四项成绩合计。
- 体育教师、家长快速核对某项成绩对应的分值与得分。

**不在覆盖范围内**

- 北京市过程性考核（40 分）部分，本工具仅计算现场考试 30 分。
- 各省市中考体育的省级或市级评分标准。各地分制、项目、评分表差异较大，未纳入本工具。
- 学校上报、等级认定等正式用途。本工具输出结果不具证明效力。

## 三、功能说明

### 3.1 国家标准（100 分制）

- **组别覆盖**：小学一年级至大学四年级共 16 个年级，男、女分开。因标准中大学一、二年级共用一套评分列，三、四年级共用一套，实际评分类别为 14 组。
- **指标构成**：体重指数（BMI）、肺活量、50 米跑为各年级共有指标；小学增设 1 分钟跳绳，五、六年级另设 50 米 × 8 往返跑；初中及以上改设引体向上（男）／1 分钟仰卧起坐（女）、立定跳远与 1000 米（男）／800 米（女）跑。各组别的指标与权重详见第 4.1 节。
- **参考档位**：提供 100 / 90 / 80 / 60 四档一键填入，各输入框的灰色默认值随所选档位同步变化，可用于反查某一等级所需达到的成绩门槛。
- **附加分**：小学阶段为 1 分钟跳绳（最多 +20）；初中及以上为男生引体向上与 1000 米跑、女生 1 分钟仰卧起坐与 800 米跑（各最多 +10）。
- **总分口径**：以 100 分为满分线，附加分可使总分超过 100，最高 120；页面分母固定显示 /100，超出 100 时数值与进度条转为强调色。

### 3.2 北京市现场考试（30 分制）

四项各考 1 项，合计 30 分：

| 类别    | 分值  | 说明                           |
| ----- | --- | ---------------------------- |
| 素质项目Ⅰ | 8 分 | 1000 米（男）／800 米（女），必考        |
| 素质项目Ⅱ | 8 分 | 六选一，男女选项不同                   |
| 运动能力Ⅰ | 8 分 | 足球、篮球、排球、乒乓球、羽毛球、100 米游泳，六选一 |
| 运动能力Ⅱ | 6 分 | 四选一，动作质量 5 分 + 动作表现 1 分      |

- 素质项目Ⅱ：男生为引体向上、双杠臂屈伸、投掷实心球、1 分钟跳绳、原地纵跳摸高、立定跳远；女生为斜身引体、仰卧起坐、投掷实心球、1 分钟跳绳、原地纵跳摸高、立定跳远。
- 运动能力Ⅱ采用逐动作勾选：动作质量 5 分按漏做、做错的动作扣分，动作表现分一等 1 分，界面实时合成 6 分制得分。
- 100 米游泳在现行评分表中最高列为 6 分，页面按 6 分封顶，并在选项中标注。
- 各选考项目分别记忆已录入成绩，切换选项不丢失数据。

### 3.3 通用功能

- **结果面板**：常驻显示总分、各项得分、已填项数量与单项明细（含权重、原始成绩、得分、加权分）。
- **移动端适配**：窄屏下改为单列布局，并在屏幕底部固定显示总分条，填写过程中实时更新；当完整结果面板进入视野时自动收起，避免同一数值重复呈现。
- **成绩图片导出**：可将当前结果渲染为 1080 逻辑像素宽、2 倍分辨率的 PNG 图片，用于留存或分享。图片仅在页面内预览，由使用者手动长按或右键保存，不触发自动下载。
- **本地存档**：输入内容自动保存在浏览器本地，刷新或重新打开页面后可恢复。
- **评分表附录**：页尾折叠展示本次适用组别的全部评分表，当前适用列（性别、所选项目）高亮。
- **打印样式**：打印或导出 PDF 时自动隐藏交互控件。

## 四、计分规则

### 4.1 国家标准

**单项得分**按评分表查得，不按比例折算。每项评分表由 20 个档位构成（100 / 95 / 90 / 85 / 80 / 78 / 76 / 74 / 72 / 70 / 68 / 66 / 64 / 62 / 60 / 50 / 40 / 30 / 20 / 10），成绩达到某一档标准即得该档分值，低于最低档记 0 分。

**学年总分**为各单项得分加权求和后加附加分：

```
标准分   = Σ（单项得分 × 该项权重）÷ 100
学年总分 = 标准分 + 附加分（上限 20，总分上限 120）
```

各单项权重由标准附表规定，随组别自动套用，合计 100%：

| 测试对象        | 单项指标与权重（%）                                                           |
| ----------- | -------------------------------------------------------------------- |
| 全部年级        | 体重指数 15、肺活量 15                                                       |
| 小学一、二年级     | 50 米跑 20、坐位体前屈 30、1 分钟跳绳 20                                          |
| 小学三、四年级     | 50 米跑 20、坐位体前屈 20、1 分钟跳绳 20、1 分钟仰卧起坐 10                              |
| 小学五、六年级     | 50 米跑 20、坐位体前屈 10、1 分钟跳绳 10、1 分钟仰卧起坐 20、50 米 × 8 往返跑 10              |
| 初中、高中、大学各年级 | 50 米跑 20、坐位体前屈 10、立定跳远 10、引体向上（男）／1 分钟仰卧起坐（女）10、1000 米（男）／800 米（女）20 |

**等级**按学年总分判定：90.0 分及以上为优秀，80.0～89.9 为良好，60.0～79.9 为及格，59.9 分及以下为不及格。

**关于 BMI**：评分表仅设 100 / 80 / 60 三档，无 90 分档。故选择「90 分档」填入时，BMI 按正常区间（100 分）代入，其余各项按 90 分计，总分为 91.5。页面内已就此加注说明。

### 4.2 北京市现场考试

- 现场考试成绩 = 四项得分之和，满分 30 分。
- 各项目成绩达到评分表某一档标准即得该档分值，未达最低档记 0 分。
- 现场考试不设等级，页面给出得分率（得分 ÷ 30）作为参照。
- 体育与健康考核评价总分 70 分 = 过程性考核 40 分 + 现场考试 30 分；本工具仅计算现场考试部分。
- 2021 年方案另设分学段过渡安排（2021 年 9 月 1 日时五至七年级、三至四年级学生对应总分分别为 50 分、60 分），本工具不涉及过渡方案的计算。

## 五、数据来源与校核

两套评分表均逐格录入官方公布稿，录入结果经脚本与原文逐单元格比对，无差异。

1. **教育部《国家学生体质健康标准（2014 年修订）》**（教体艺〔2014〕5 号），含附件中的全部单项评分表与加分表。  
   <https://www.moe.gov.cn/jyb_xxgk/xxgk/neirong/fenlei/sxml_twyjy/twyjy_tyws/tyws_xgzc/201407/t20140708_171692.html>
2. **北京市教育委员会《北京市义务教育体育与健康考核评价方案》**（京教体艺〔2021〕31 号，2021 年 12 月 9 日公布）。现场考试对象为九年级学生，四类各考 1 项，满分 30 分。  
   <https://www.beijing.gov.cn/zhengce/zhengcefagui/202112/t20211209_2557431.html>
3. **北京教育考试院《北京市义务教育体育与健康考核评价现场考试项目评分标准（试行）》**（2023 年 11 月 24 日公布），为上述方案的配套评分标准。  
   <https://www.bjeea.cn/html/zkzz/tzgg/2023/1124/84611.html>

**一处编排差异的说明**：2021 年方案附件 2 将 100 米游泳列在运动能力Ⅱ（6 分档），2023 年评分表则将其编排在运动能力Ⅰ。本工具以 2023 年评分表为准。

## 六、技术实现

| 项目     | 说明                                                           |
| ------ | ------------------------------------------------------------ |
| 形态     | 单个 `index.html`（约 121 KB），HTML、CSS、JavaScript 内联             |
| 依赖     | 无。不引用任何框架、字体或 CDN 资源，网络请求数为 0                                |
| 兼容性    | 支持桌面与移动端现代浏览器，含 Chrome、Safari、Edge、Firefox 及微信内置浏览器          |
| 存储     | 使用浏览器 `localStorage` 保存输入（键名 `tizhi-2014-calc-v1`），清除站点数据即失效 |
| 图片导出   | Canvas 2D 绘制，2 倍分辨率输出 PNG，白色背景铺实，未使用第三方绘图库                   |
| 响应式断点  | 920px（布局转单列）、620px（表单与字号调整）、高度 540px（横屏适配）                   |
| 脚本失效保护 | 若页面脚本被拦截，显示明确提示，不出现空白页                                       |

评分数据以常量形式内置：分档数组共 20 项，各评分表按「行 = 档位、列 = 组别」组织。查表时区分两类指标——时间型（值越小越好，如 50 米跑、耐力跑）与计次计距型（值越大越好，如肺活量、跳绳、引体向上）。

## 八、已知限制

1. **不具证明效力**。结果为自测估算值，最终成绩以学校或考试机构核定为准。
2. **北京市仅覆盖九年级**。北京市考核评价在四、六、八年级另设过程性考核项目，本工具未纳入。
3. **省级中考体育标准未收录**。上海、天津、陕西等地的现场测试评分标准分制各异（15 至 100 分不等），与上述两套标准不具备可比性，未做适配。
4. **数据时效**。评分标准可能随政策修订，本工具录入的是上述文件公布时的版本，不保证与最新文件同步。
5. **不支持多用户对照**。单次仅计算一名学生的成绩。
