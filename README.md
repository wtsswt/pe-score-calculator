# 体测成绩计算器 · 国家学生体质健康标准（2014 年修订）

按《国家学生体质健康标准（2014 年修订）》评分表实现的单页计算器：选年级、选性别、填成绩，实时按权重折算标准分、累计附加分并评定等级。

**在线使用** → https://wtsswt.github.io/pe-score-calculator/

## 功能

- 覆盖小学一年级至大学四年级共 16 个组别，男女分开，指标与权重随组别自动切换
- 小学含 1 分钟跳绳（五、六年级另加 50 米 × 8 往返跑）；初中以上换成引体向上（男）/ 1 分钟仰卧起坐（女）与 1000 / 800 米跑
- 参考档位 100 / 90 / 80 / 60：切换档位时各输入框的灰色默认值同步变化，也可一键填入整档成绩
- 附加分按学段实现：小学 1 分钟跳绳最多 +20；初中以上引体向上 / 仰卧起坐、耐力跑各最多 +10
- 学年总分以 100 分为满分线，附加分可使总分超过 100（最高 120）
- 右侧常驻结果面板：总分、标准分、附加分、已填项、等级与单项明细（项目 / 权重 / 成绩 / 得分 / 加权）
- 页尾折叠展示全部评分表，当前年级对应列高亮
- 输入内容自动保存在本机浏览器，刷新不丢；支持打印样式
- 单文件、零依赖、不发任何网络请求，断网也能用

## 使用

下载 `index.html` 双击打开即可，或直接用上面的在线链接。

## 规则说明

- 学年总分 = 标准分（各单项得分 × 权重求和，满分 100）+ 附加分（最多 20）
- 等级：≥ 90 优秀、80—89.9 良好、60—79.9 及格、59.9 及以下不及格
- BMI 只有 100 / 80 / 60 三档，故选择 90 分档时按"正常"区间代入，总分为 91.5（页面内已注明）
- 结果仅用于自测估算，最终成绩以学校体育教学部核定为准

## 数据来源

评分表取自教育部《国家学生体质健康标准（2014 年修订）》通知（教体艺〔2014〕5 号）及其附件中的附表 1-1 ~ 2-6。
