# 体测成绩计算器

按现行评分标准查单项得分、算学年总分与等级。页面顶部切换标准。

在线：<https://wtsswt.github.io/pe-score-calculator/>

## 覆盖范围

| 标准 | 对象 | 分制 |
| --- | --- | --- |
| 《国家学生体质健康标准（2014 年修订）》 | 小学一年级至大学四年级，16 个年级 | 100 分制，另设附加分 |
| 《北京市义务教育体育与健康考核评价现场考试项目评分标准（试行）》 | 九年级 | 30 分制 |

北京市部分仅计现场考试 30 分，不含过程性考核 40 分；各省市中考体育标准未收录。

## 功能

- 按组别自动套用指标与权重：小学至大学 16 个年级、男女分开，因大学一/二年级、三/四年级各共用一套评分列，实际为 14 组
- 100 / 90 / 80 / 60 四档一键填入，用于反查某一等级所需的成绩门槛
- 结果面板常驻显示总分、等级、单项明细（权重、原始成绩、得分、加权分）
- 各选考项目分别记忆已录入成绩，切换选项不丢数据
- 成绩图导出为 PNG（1080 逻辑像素宽、2 倍分辨率）；输入内容存浏览器本地
- 页尾折叠展示本次适用组别的完整评分表，当前列高亮；打印时隐藏控件

## 计分

单项得分按评分表查得，不按比例折算。每项 20 个档位（100 / 95 / 90 / … / 10），达到某档标准即得该档分值，低于最低档记 0 分。

```
标准分   = Σ（单项得分 × 该项权重）÷ 100
学年总分 = 标准分 + 附加分（附加分上限 20，总分上限 120）
等级     = ≥90 优秀 / 80–89.9 良好 / 60–79.9 及格 / <60 不及格
```

权重（%），合计 100：

| 组别 | 指标与权重 |
| --- | --- |
| 全部年级 | 体重指数 15、肺活量 15 |
| 小学一、二年级 | 50 米跑 20、坐位体前屈 30、1 分钟跳绳 20 |
| 小学三、四年级 | 50 米跑 20、坐位体前屈 20、1 分钟跳绳 20、仰卧起坐 10 |
| 小学五、六年级 | 50 米跑 20、坐位体前屈 10、1 分钟跳绳 10、仰卧起坐 20、50 米 × 8 往返跑 10 |
| 初中至大学 | 50 米跑 20、坐位体前屈 10、立定跳远 10、引体向上（男）/ 仰卧起坐（女）10、1000 米（男）/ 800 米（女）20 |

附加分：小学为 1 分钟跳绳（最多 +20）；初中及以上为男生引体向上与 1000 米、女生仰卧起坐与 800 米（各最多 +10）。

BMI 评分表只有 100 / 80 / 60 三档，没有 90 分档，因此选「90 分档」填入时 BMI 按 100 分代入，总分为 91.5。

北京市现场考试：素质项目Ⅰ 8 分（耐力跑、必考）、素质项目Ⅱ 8 分（六选一）、运动能力Ⅰ 8 分（球类或游泳六选一）、运动能力Ⅱ 6 分（四选一，动作质量 5 + 动作表现 1）。四项之和满分 30，不设等级，页面给出得分率。100 米游泳在现行表中最高 6 分，按 6 分封顶。

## 已知限制

1. 结果为自测估算，不具证明效力，最终成绩以学校核定为准。
2. 北京市仅覆盖九年级现场考试，四、六、八年级的过程性考核未纳入。
3. 评分标准可能随政策修订，不保证与最新文件同步。
